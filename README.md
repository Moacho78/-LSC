# 🤟🧠 SEMAK 

SEMAK es una aplicación web desarrollada con **HTML, CSS, JavaScript, Node.js  Express** enfocada en el reconocimiento y aprendizaje de la **Lengua de Señas Colombiana (LSC)** mediante el análisis de rasgos manuales y tecnologías de visión por computador.  

El proyecto busca fortalecer la inclusión y accesibilidad comunicativa entre personas sordas y oyentes, ofreciendo una plataforma interactiva capaz de interpretar señas y apoyar procesos educativos relacionados con la Lengua de Señas Colombiana.

---

# 🚀 Características  

## 🤟 Reconocimiento de señas  
El sistema permite identificar señas de la Lengua de Señas Colombiana mediante el análisis de movimientos y configuraciones manuales.

## 📷 Captura en tiempo real  
Uso de la cámara del dispositivo para detectar y procesar señas en tiempo real.

## 🧠 Análisis de rasgos manuales  
El sistema interpreta parámetros fundamentales de la LSC como:

- Configuración manual  
- Orientación de la mano  
- Movimiento    

## 📚 Módulo educativo  
Incluye contenido visual e interactivo para facilitar el aprendizaje de la Lengua de Señas Colombiana.

## 🔐 Gestión de usuarios  
Registro e inicio de sesión para acceso a la plataforma.

## ☁️ Almacenamiento de información  
Gestión segura de usuarios y registros mediante base de datos integrada con el backend.

## 🎨 Interfaz intuitiva  
Diseño accesible y amigable enfocado en mejorar la experiencia de usuario.

## 🤖 Procesamiento inteligente  
Uso de modelos de visión artificial e inteligencia artificial para mejorar la precisión en el reconocimiento de señas.

# 💻 Instalación y Ejecución  

El proyecto se encuentra dividido en dos partes:

- **Frontend:** desarrollado con HTML, CSS y JavaScript.
- **Backend:** desarrollado con Node.js y Express.

Sigue estos pasos para ejecutar correctamente el sistema.

---

# ⚙️ Requisitos Previos  

Antes de iniciar, asegúrate de tener instalado:

- Node.js  
- npm  
- Git  

Verifica las versiones instaladas:

```bash
node -v
npm -v
git --version
```

---

# 📥 Clonar el repositorio  

```bash
git clone https://github.com/USUARIO/LSCVision.git
cd LSCVision
```

---

# ⚙️ Configuración del Backend  

Ingresa a la carpeta del backend:

```bash
cd backend
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el servidor:

```bash
npm start
```

O en modo desarrollo:

```bash
npm run dev
```

El backend se ejecutará normalmente en:

```bash
http://localhost:3000
```

---

# 🎨 Configuración del Frontend  

Ingresa a la carpeta del frontend:

```bash
cd frontend
```

Abre el archivo `index.html` directamente en el navegador
